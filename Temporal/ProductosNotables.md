
## Binomio al cuadrado: $(a \pm b)^2 = a^2 \pm 2ab + b^2$

### Ejercicio 1
* **Expresión:** $(r - 5)^2$
* **Procedimiento:**
  1. Cuadrado del primer término: $r^2$
  2. Doble producto del primero por el segundo: $2(r)(-5) = -10r$
  3. Cuadrado del segundo término: $(-5)^2 = 25$
* **Respuesta:** $r^2 - 10r + 25$

---

### Ejercicio 2
* **Expresión:** $(7 + 3r)^2$
* **Procedimiento:**
  1. Cuadrado del primero: $7^2 = 49$
  2. Doble producto: $2(7)(3r) = 42r$
  3. Cuadrado del segundo: $(3r)^2 = 9r^2$
* **Respuesta:** $49 + 42r + 9r^2$ (o $9r^2 + 42r + 49$)

---

## Binomios conjugados (Diferencia de cuadrados): $(a + b)(a - b) = a^2 - b^2$

### Ejercicio 9
* **Expresión:** $(7n + 2)(7n - 2)$
* **Procedimiento:**

  3. Resta de ambos cuadrados: $49n^2 - 4$
* **Respuesta:** $49n^2 - 4$

## Producto de dos binomios con un término en común: $(ax + b)(cx + d)$

### Ejercicio 17
* **Expresión:** $(8m + 8)(8m + 5)$
* **Procedimiento:**
  1. Término común al cuadrado: $(8m)^2 = 64m^2$
  2. Suma de no comunes por el común: $(8 + 5)(8m) = 13(8m) = 104m$
  3. Producto de no comunes: $(8)(5) = 40$
* **Respuesta:** $64m^2 + 104m + 40$

---

### Ejercicio 18

  3. Producto de no comunes: $(8)(6) = 48$
* **Respuesta:** $25p^2 + 70p + 48$

---

## Binomio al cubo: $(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$

### Ejercicio 25
* **Expresión:** $(y^4 + 4x)^3$
* **Procedimiento:**
  1. $a^3 = (y^4)^3 = y^{12}$
  2. $3a^2b = 3(y^4)^2(4x) = 3(y^8)(4x) = 12xy^8$
  3. $3ab^2 = 3(y^4)(4x)^2 = 3(y^4)(16x^2) = 48x^2y^4$
  4. $b^3 = (4x)^3 = 64x^3$
* **Respuesta:** $y^{12} + 12xy^8 + 48x^2y^4 + 64x^3$

---

### Ejercicio 26
* **Expresión:** $(4x^2 + 1)^3$
* **Procedimiento:**
  1. $a^3 = (4x^2)^3 = 64x^6$
  2. $3a^2b = 3(4x^2)^2(1) = 3(16x^4)(1) = 48x^4$
  3. $3ab^2 = 3(4x^2)(1)^2 = 12x^2$
  4. $b^3 = 1^3 = 1$
* **Respuesta:** $64x^6 + 48x^4 + 12x^2 + 1$

---

### Ejercicio 27
* **Expresión:** $(4x^2 + y)^3$
* **Procedimiento:**
  1. $a^3 = (4x^2)^3 = 64x^6$
  2. $3a^2b = 3(4x^2)^2(y) = 3(16x^4)(y) = 48x^4y$
  3. $3ab^2 = 3(4x^2)(y)^2 = 12x^2y^2$
  4. $b^3 = y^3$
* **Respuesta:** $64x^6 + 48x^4y + 12x^2y^2 + y^3$

---

### Ejercicio 28
* **Expresión:** $(x - y)^3$
* **Procedimiento:**
  1. $a^3 = x^3$
  2. $-3a^2b = -3x^2y$
  3. $+3ab^2 = 3xy^2$
  4. $-b^3 = -y^3$
* **Respuesta:** $x^3 - 3x^2y + 3xy^2 - y^3$

---

### Ejercicio 29
* **Expresión:** $(3m + n)^3$
* **Procedimiento:**
  1. $a^3 = (3m)^3 = 27m^3$
  2. $3a^2b = 3(3m)^2(n) = 3(9m^2)(n) = 27m^2n$
  3. $3ab^2 = 3(3m)(n)^2 = 9mn^2$
  4. $b^3 = n^3$
* **Respuesta:** $27m^3 + 27m^2n + 9mn^2 + n^3$

---

### Ejercicio 30
* **Expresión:** $(y + 4)^3$
* **Procedimiento:**
  1. $a^3 = y^3$
  2. $3a^2b = 3(y)^2(4) = 12y^2$
  3. $3ab^2 = 3(y)(4)^2 = 3(y)(16) = 48y$
  4. $b^3 = 4^3 = 64$
* **Respuesta:** $y^3 + 12y^2 + 48y + 64$

---

### Ejercicio 31
* **Expresión:** $(4m + 2n^2)^3$
* **Procedimiento:**
  1. $a^3 = (4m)^3 = 64m^3$
  2. $3a^2b = 3(4m)^2(2n^2) = 3(16m^2)(2n^2) = 96m^2n^2$
  3. $3ab^2 = 3(4m)(2n^2)^2 = 3(4m)(4n^4) = 48mn^4$
  4. $b^3 = (2n^2)^3 = 8n^6$
* **Respuesta:** $64m^3 + 96m^2n^2 + 48mn^4 + 8n^6$

---

### Ejercicio 32
* **Expresión:** $(y^2 - 5)^3$
* **Procedimiento:**
  1. $a^3 = (y^2)^3 = y^6$
  2. $-3a^2b = -3(y^2)^2(5) = -15y^4$
  3. $+3ab^2 = 3(y^2)(5)^2 = 3(y^2)(25) = 75y^2$
  4. $-b^3 = -(5)^3 = -125$
* **Respuesta:** $y^6 - 15y^4 + 75y^2 - 125$
